# Лабораторная работа 1

## Цель

Сформировать с помощью веб-страницы [Yandex Images](https://yandex.ru/images/) датасет из двух классов:

- `cat` — не менее 1000 изображений кошек;
- `dog` — не менее 1000 изображений собак.

Скачиваются исходные изображения из результатов Яндекс.Картинок, а не миниатюры.

## Структура проекта

```text
lab_yandex_images/
├── main.py
├── requirements.txt        # pip freeze > requirements.txt
├── README.md
├── notebook.ipynb
├── manifest.jsonl          # создаётся скриптом
└── dataset/                # создаётся скриптом
    ├── cat/
    └── dog/
```

Папки `dataset/cat` и `dataset/dog` не создаются вручную: они автоматически создаются вызовом `Path.mkdir(..., parents=True)`.

## Как выполнены требования задания

1. Источник поиска — `https://yandex.ru/images/search`.
2. Для каждого класса используются несколько поисковых запросов: английские и русские варианты.
3. Из HTML извлекается `img_href`, то есть ссылка на исходное изображение, а не URL миниатюры.
4. Перед сохранением файл открывается Pillow и проверяется как изображение.
5. Для полноразмерного режима используется оригинальный URL, а минимальная сторона принятого изображения ограничена `600` пикселями.
6. Все результаты сохраняются с расширением `.jpg`.
7. Имя файла строится через `str.zfill(4)`: `0000.jpg`, `0001.jpg`, ..., `0999.jpg`.
8. Дубли исключаются по SHA-256, а уже использованные URL дополнительно сохраняются в `manifest.jsonl`.
9. При повторном запуске скрипт продолжает заполнение недостающих позиций, поэтому после ручной проверки можно удалить ошибочные изображения и снова запустить `main.py`.
10. Запросы и страницы сохраняются в манифесте, что позволяет объяснить происхождение каждого изображения.

## Ручная проверка

После выполнения скрипта(можно и во время выполнения, фотографии скачиваются постепенно) нужно просмотреть `dataset/cat` и `dataset/dog`. Если найдено изображение не того класса, его надо удалить. Скрипт увидит недостающее количество файлов и загрузит новые изображения, при этом уже использованные URL и хэши повторно не возьмёт. Даже если пришлось удалить изображение из середины датасета, новое будет добавлено на место удаленного.
